# ynera-legal

Public web pages for **Ynera: Orbit Dodge** — a one-tap orbit arcade game for iOS.

**Live:** [harundogdu.github.io/ynera-legal](https://harundogdu.github.io/ynera-legal/)

## What's inside

- `index.html` — landing page for the game (TR/EN)
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `style.css` — shared styles

## Notes

- Plain static HTML/CSS, no build step — open in a browser or serve with
  `python3 -m http.server`.
- Bilingual content (Türkçe / English) on every page.
- Hosted on **GitHub Pages** (branch `main`, root); every push deploys automatically.
- These URLs are referenced from App Store Connect (Privacy Policy / Support links).
